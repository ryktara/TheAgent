# ADR 0009: Internationalisation and RTL

## Context

Region PK; receipt languages en, ur [D:region]. Arabic needs right-to-left layouts; numbers, prices and charts stay left-to-right.

## Decision

ICU message catalogs per language; logical CSS properties throughout; full mirroring for RTL except numerals, prices, numpads, QR codes and chart coordinates; instruments carry name per language; receipts render both blocks with identical totals; locale-aware number and date formatting with Western numerals by default and Arabic-Indic per branch setting.

## Alternatives

| Alternative | Rejected because |
|-------------|------------------|
| English-only first release | receipt language is a legal requirement in the region |
| Machine-translated UI | operational terms need reviewed translations |

## Consequences

- Every screen spec carries an RTL note
- Pseudo-localisation test in CI
- Fonts with Naskh/Nastaliq fallback

## Revisit when

A language outside en, ar, ur is required.
