# Page overrides

Create `pages/<screen-id>.md` with any of the MASTER.md headings (`## Palette`, `## Typography`, `## Scales`, `## Components`, `## Do and avoid`, `## RTL`, `## Print`). A section present here replaces the same section of MASTER.md for that screen only; absent sections inherit. Keep overrides rare and cite the ux-rule id that justifies them.
